# Documentation

This directory contains the DocFX configuration for generating API reference documentation.

## View the Docs

- **[API Reference](https://zone117x.github.io/Secp256k1.Net/api/Secp256k1Net.Secp256k1.html)** - Full API documentation
- **[Examples](../Secp256k1.Net.Examples/)** - Working code examples

## Build Locally

```bash
./docs/build.sh        # Build docs
./docs/build.sh --serve # Build and preview at http://localhost:8080
```
